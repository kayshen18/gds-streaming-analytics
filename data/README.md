# Local data

Place the course-provided GDS source file at:

```text
data/raw/kafka采集数据实验.txt
```

The full source is intentionally excluded from Git because its redistribution rights are not established. Only synthetic fixtures under `tests/fixtures/` are publishable with this repository.

Every full run records the source byte size and SHA-256 digest, allowing results to be tied to the exact local file without publishing that file.
